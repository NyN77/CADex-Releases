# CADex — установщики и обновления

Готовые пакеты CADex для Windows x64 и КОМПАС-3D v23. Исходники хранятся отдельно в приватном репозитории.

- **[Скачать полный установщик CADex 1.0.3](https://github.com/NyN77/CADex-Releases/releases/download/v1.0.3/CADex-Setup-1.0.3.exe)**
- [Мини-пакеты обновления и описание 1.0.3](https://github.com/NyN77/CADex-Releases/releases/tag/v1.0.3)
- [Все выпуски](https://github.com/NyN77/CADex-Releases/releases)

Начиная с 1.0.3 CADex автоматически проверяет обновления при запуске и каждые 6 часов. Программа предлагает подходящий мини-пакет с размером; промежуточные версии устанавливать не нужно. Если пакет для исходной сборки отсутствует, предлагается полный установщик.

Для первого перехода со старой 1.0.1/1.0.2 скачайте установщик или соответствующий мини-пакет со страницы выпуска. Старый интерфейс проверки обновлений ещё обращается к приватному адресу. Мини-пакет проверит точную исходную сборку; при несовпадении используйте полный установщик.

Сохраните работу и закройте CADex и КОМПАС перед установкой. Затем откройте новую задачу Codex для загрузки обновлённого плагина. Установка не закрывает пользовательские документы. Каждый EXE сопровождается SHA-256.

В 1.0.3 исправлена подготовка зависимостей моста, из-за которой 1.0.2 могла не загружаться на другом ПК. Полная приёмка сложных CAD-сценариев остаётся отдельной работой; productionApproved=false сохранён.
