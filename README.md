# CADex — установщики

Публичный репозиторий готовых установщиков CADex. Исходный код и история разработки хранятся отдельно и здесь не публикуются.

## Скачать

- [CADex 1.0.2](https://github.com/NyN77/CADex-Releases/releases/tag/v1.0.2)
- [CADex 1.0.1](https://github.com/NyN77/CADex-Releases/releases/tag/v1.0.1)

В каждом выпуске доступны EXE установщика и файл SHA-256. Это исходные опубликованные сборки соответствующих версий, без пересборки.

Платформа: Windows x64, КОМПАС-3D v23. Перед установкой или обновлением сохраните работу и закройте КОМПАС и CADex.

## Известное ограничение 1.0.2

На отдельном ПК подтверждена ошибка загрузки моста КОМПАСа из-за зависимостей API. Исправление подготовлено в разработке, но в установщик 1.0.2 не входит. Публикация файлов здесь не означает новую сборку или устранение этой ошибки.

Скачивание из этого репозитория не требует доступа к закрытому исходному коду. Встроенная проверка обновлений в старых версиях ещё может обращаться к прежнему закрытому адресу; новые выпуски проверяйте на этой странице.
